## 原作对照与数值处理

在相同 **1440×900 / 原作第 7 秒**比较未修改的 `original.glsl`、TSL WebGL2 和 TSL WebGPU。参考 GLSL 在独立 WebGL2 画布编译，嵌入源字符逐字相等，draw error=0，所有页面错误/警告为零。

| 比较                    | 平均 RGB byte 差 | 最大差 | RGB 分量差>10 的比例 |
| ----------------------- | ---------------: | -----: | -------------------: |
| 原始 GLSL → TSL WebGL2  |     0.0057286523 |    105 |     0.00000257201646 |
| TSL WebGPU → TSL WebGL2 |     0.0002062757 |    105 |     0.00000128600823 |

已人工对照原始画面与两后端，弯曲方向、壳纹层次、暗部和蓝青色外缘一致。很小的平均差仍伴随少量显著分量差，不能宣称逐像素相同，也没有把差异归因于已被证明的单一浮点原因。该比较仅覆盖默认第 7 秒，不外推为所有时间和全部参数的跨后端一致性证明。

TSL 保留底边中央原点、行向量乘矩阵方向、逐分量坐标乘法、三通道连续状态和无界 `mix` 权重。半径除数使用 `1e-6` 下限，第一通道零次幂直接取一，源 `pow(uv.y,1.0)` 以有符号纵坐标代替；最终 RGB 裁剪后进行一次 sRGB 解码。原始快照未修改，详见 `LICENSE.md` 的字节哈希与修改说明。

## 运行时与本机基线

| 视口/后端       | 绘图缓冲 | 有效 DPR | 平均 RAF 间隔 |    P95 |
| --------------- | -------- | -------: | ------------: | -----: |
| 桌面 WebGPU     | 1440×900 |        1 |       6.06 ms | 6.1 ms |
| 桌面 WebGL2     | 1440×900 |        1 |       6.06 ms | 6.1 ms |
| 移动模拟 WebGPU | 618×1372 |      1.5 |       6.06 ms | 6.1 ms |
| 移动模拟 WebGL2 | 618×1372 |      1.5 |       6.06 ms | 6.1 ms |

每组预热 3 秒后记录 120 个 RAF 间隔，逐个案例执行。这是浏览器调度间隔，**不是 GPU 执行时间、真实手机性能或跨设备帧率保证**。本案例每像素固定三次二维通道递进，没有纹理、三维步进或额外 pass；高频条纹仍可能有锯齿。

- 自动 DPR：受控 130 帧、每帧 45 ms 主线程负载，**1→0.8**。仅证明自适应路径工作，不代表自然 Shader 成本为 45 ms。
- 减少动态效果：初始没有 GPU 后端，海报正常加载；用户点击播放后实际 WebGPU 启动。
- **受控隐藏事件**：`document.hidden=true`，800 ms 内 GPU submits **582→582**，按钮为「播放动画」；恢复后 submits=718，按钮为「暂停动画」。
- **原生后台标签页暂停未验证**：实际切换到另一标签后，`document.hidden` 仍为 false。虽 GPU submits 暂时 478→478，仍不能把这当作原生 Page Visibility 暂停的证据。受控测试与原生能力边界分别记录。
