## 图像、参数与媒体

- 新案例桌面/移动 × WebGPU/WebGL2 四组回归通过：云层有颜色及亮度范围、无外部素材请求，五参数均可改变画布并恢复。
- 独立五参数 × 双后端共十组通过；九组恢复完全一致。WebGL2 细节明暗恢复有 320 个通道相差 1/255，平均 RGBA 字节差 0.0000617284。原因未确定，不声明所有恢复帧字节完全一致。
- 回归预设容差为最大每通道差 ≤1/255、平均 RGBA 字节差 <0.0001；冻结时间、固定画质并隐藏 UI 后比较画布截图。
- 原作与 TSL 保留相同 hash 与公式，但三角函数及后续浮点运算可能受驱动/backend 影响。默认原始 GLSL 与 TSL WebGL2 在相同时刻/尺寸另作实际画布截图比较，最大通道差 1/255，平均 RGB 字节差 0.0243871，见 reference-comparison.json。跨后端不要求逐像素一致。
- 无页面/控制台错误、外部素材请求或横向溢出；查看默认海报、视频中间帧、移动界面及极值画面。
- 海报为真实 WebGPU 画布 1440×900 的 WebP；无声 VP8 WebM 1440×900 / 25fps / 7.52s，首尾 0.5s 交叉淡化。不是原作严格周期动画。

## 播放行为

- 降动效：首次只显示已加载海报，backend 尚未初始化；用户主动播放后启动渲染。
- 自适应 DPR：真实页面注入每帧约 45ms 的主线程负载后，由 1 降至 0.8。只证明受控慢帧下降级逻辑有效，不代表默认云层自然触发降级。
- 受控隐藏事件：模拟 document.hidden=true 并派发 visibilitychange，GPU 提交计数 8→8，持续 800ms；恢复后增至 144。只验证事件逻辑。
- **真实后台暂停仍未验证**：headless 最小化仍为 hidden=false；另外启动可见 Chromium，移除禁用后台节流的默认参数、禁用焦点模拟并实际切换标签页，仍未观察到 hidden=true 或 visibilitychange（native-visibility.json）。因此不把真实后台路径计为通过。这是自动化环境限制；未改动站点暂停实现。

## 性能基线

独立顺序采集，四组各预热 3 秒并记录 120 个 RAF 间隔。均值 6.06ms，p95 6.1–6.2ms；桌面画布 1440×900，移动模拟画布 618×1372。详见 performance.json。

RAF 是浏览器调度间隔，不是 GPU timestamp 耗时，不证明真实手机帧率。默认每像素 37 次噪声采样；高 DPR 会增加像素成本。
