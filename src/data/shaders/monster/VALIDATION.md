## 原作对照与数值边界

在 1440×900、原作时间 2 秒对照未修改的 `original.glsl` 和默认 TSL；参考画布 alpha:false，以不透明方式显示原始 RGB。嵌入源码逐字相等，WebGL draw error=0，页面错误/警告为零。

| 比较                    | 平均 RGB byte 差 | 最大差 | RGB 分量差>10 的比例 |
| ----------------------- | ---------------- | ------ | -------------------- |
| 原始 GLSL → TSL WebGL2  | 0.0096851852     | 255    | 0.00000308642        |
| TSL WebGPU → TSL WebGL2 | 0.0356514918     | 255    | 0.00010853909        |

画面对照已人工检查，青绿隧道、黑色间隙和局部亮片一致。最大差表明仍有少量明显分量差异；不能用很小的平均值宣称逐像素相同，也未证明这些差异都来自单一浮点根因。

保留原作 66 次推进、四层默认折叠、零步长重复计数与默认颜色。添加零半径 `atan(0,0)` 防护，倒数切片恰好为零时取正侧饱和极限；原始快照没有改动。SHA256 和修改说明见 `LICENSE.md`。

## 运行时行为与本机基线

- 每组预热 3 秒后记录 120 个 RAF 间隔。桌面 1440×900 / DPR1，移动模拟 412×915 / DPR1.5；四组平均 6.06 ms，P95 6.1–6.2 ms；无横向溢出和外部请求。
- 这是调度间隔基线，不是 GPU 时间戳、移动硬件帧率或跨设备性能保证。默认每像素 66 次场查询，每次四层折叠；增加折叠次数的成本未单独量化。
- 130 帧受控 45 ms 主线程负载：自动 DPR 1→0.8。证明调节路径工作，不代表自然 Shader 成本为 45 ms。
- `prefers-reduced-motion: reduce`：初始无 GPU 后端，海报加载完成；点击播放后实际 WebGPU 启动。
- 受控隐藏事件：800 ms GPU submits `530→530`，按钮显示「播放动画」；恢复后 submits=666，按钮为「暂停动画」。
- 原生标签切换：`document.hidden` 始终为 false，虽 submits 暂时 `424→424`，仍不能证明 Page Visibility 原生隐藏路径。**原生后台标签页暂停未验证**；受控结果必须独立标注。

完整硬件、适配器、视口、DPR、计时与事件记录保存在 `performance.json` 和 `browser-evidence.json`。

## 诊断保留与远端边界

奇数视口诊断脚本首次因自身重复 Canvas2D 读取触发 `willReadFrequently` 建议警告。只给诊断读取器添加该选项，六组重跑全部无警告；原日志保留在 `output/playwright/monster-extremes-first.log`，未修改产品代码来掩盖该提示。

PR CI 的结论以最终提交对应的远端运行记录为准。本机实际非 fallback WebGPU 证据与远端 CI 必须分开：若远端没有可用适配器，WebGPU 用例会跳过，不能称为远端硬件验证。PR 合并由用户最终审批；没有自动合并、Pages 修改或提前发布。
