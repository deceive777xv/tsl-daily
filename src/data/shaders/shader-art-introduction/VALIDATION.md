# 叠环流彩 — 验证记录

## 范围与设备

- 2026-09-18，本机 Windows；AMD Ryzen 9 7950X3D / NVIDIA RTX 4080 SUPER。
- Chromium 151.0.7922.34；WebGPU adapter 为 nvidia/lovelace，非 fallback。
- 生产构建，默认 WebGPU 与 `?renderer=webgl` 强制 WebGL2；两条路径均明确检查实际 backend，不将后备成功冒充 WebGPU 成功。
- 桌面 1440×900 / DPR 1；移动模拟 412×915 / deviceScaleFactor 2.625，运行时自适应 DPR 上限 1.5。不是实体手机。

## 功能与图像

- 五个参数在两后端均改变实际画布；冻结时间、固定画质、隐藏 UI 后截图比较，防止控件数值变化被误当作 Shader 变化。
- 桌面与移动专属回归验证非黑屏、颜色差异和亮度范围；默认纯白像素比例须小于 35%。极值组合允许更亮，不将最大层数/频率/辉光的饱和外观当作默认质量。
- 原始 GLSL 筛查预览与 TSL 默认海报视觉对照：递归圆环/菱形、中心暗部及颜色层次一致。默认海报、视频中间帧、移动端与参数极值已人工检查。
- 恢复帧不是承诺跨后端逐像素一致。早期 WebGL2 在平铺倍率恢复后有 135 个通道相差 1/255，均值 0.00002604 字节；三次孤立重测完全一致。后续完整序列在层数/平铺恢复时观察到 130 个通道的同等误差，具体舍入来源未确定。
- 回归容差严格限制每通道差异 ≤1/255，按 RGBA 所有通道计算的平均字节差 <0.0001，不允许可见纹样位移。最终各参数的精确差异保存在 browser-evidence.json；不把稀疏容差通过称作完全一致。
- 无页面/控制台错误、无外部素材请求；桌面和移动无横向溢出。

## 播放行为

- `prefers-reduced-motion: reduce` 首次只显示已加载海报、不初始化 backend；用户主动播放后启动实时渲染。
- 自适应 DPR：在真实运行页面注入每帧约 45ms 的主线程负载，DPR 从 1 降到 0.8。测试证明降级机制工作，不代表自然负载下必然发生降级。
- 受控隐藏事件：将 document.hidden 设为 true 后发 visibilitychange，实测 GPU 提交计数停止；还原后恢复。准确计数在 browser-evidence.json。
- **真实后台切换仍未验证**：自动化 Chromium 的窗口最小化尝试仍报告 hidden=false，不能把它作为后台暂停通过。受控属性测试只验证事件处理逻辑，不能替代操作系统真实后台/恢复路径。这是当前环境限制，未修改站点暂停逻辑。

## 性能基线

performance.json 保存独立顺序采集结果：每组先预热 3 秒，再采集 120 个 RAF 间隔（丢弃首个未配对时间戳）。四组默认参数均约 6.06ms，p95 约 6.1–6.2ms；移动内部画布约 618×1372，实际值以 JSON 为准。

这些数值是浏览器 RAF 调度间隔，受显示刷新率约束；不是 GPU timestamp query、不是每帧 Shader 执行时间，不证明真实手机达到相同帧率。六层高频极值只做视觉检查，不宣称性能等同默认四层。

## 预览产物

- WebP：1440×900，实际 WebGPU 画布截图转换，默认参数、原作时间 t=2。
- WebM：实际 WebGPU Canvas captureStream + MediaRecorder，VP8、1440×900、25fps、约 7.52 秒，无音轨。
- 8 秒录制片段用 0.5 秒交叉淡化衔接首尾；不是原公式的严格数学周期。没有下载原作视频、声音或图片。

## 完整性

mirror.json 必须与获批候选 JSON 字节一致（SHA-256 见 LICENSE.md），original.glsl 必须与镜像唯一 Image pass 解码文本一致。镜像排除格式化；不改变源文件来匹配运行版的除零保护、参数或起始时间。

本地命令结论和远端 CI 链接记录于 PR；CI 提供 site-preview 构建产物供下载，不自动部署或合并本 PR。

## 最终本地命令结果

- `npm run quality`：格式、ESLint、13 个案例契约、5 个单元测试、Astro 类型检查与生产构建通过。现有大型 chunk 提示不影响成功；本地忽略目录旧脚本有一个 unused hint，未纳入本 PR。
- `npm run test:browser`：**56 passed / 2 skipped / 0 failed / 0 flaky**。两项 skip 是既有 Pretty Hip 固定桌面边缘测试在移动配置中的主动跳过；本案例四组桌面/移动 WebGPU/WebGL2 均实际执行。
- 独立最终参数检查：10/10 改变且恢复，最终此轮全部像素一致；保留前述已观察到的稀疏误差与严格容差说明。
- 最终受控隐藏：GPU 提交 10 → 10（800ms），恢复后 148；真实最小化仍 hidden=false、16 → 18，因此真实后台路径未验证。
- 镜像 SHA-256 和 original.glsl 与镜像文本精确比对通过；最终 WebM ffprobe 确认 VP8/1440×900/25fps/7.52s，只有视频流。
