# 双流染境验证记录

选题、批准与初始诊断：2026-10-26；最终构建、回归与媒体复核：2026-10-27。来源：Paint streams — michael0884 / Mykhailo Moroz（WtfyDj）。本地结果与远端 CI 结果分别记录；PR 合并仍由用户批准。

## 源码与实现范围

原始 JSON 与 Image、Common、Buffer A/B/C 五段 GLSL 均按字节保存，字节数、SHA256 与固定镜像 Git blob 见 `source-hashes.json`。辅助 `hash32` 的完整 MIT Common 快照另存；全部来源与许可证据见 `LICENSE.md`。

TSL 保留原作的重积分、局部压力、注流、边界、密度与显示公式。两个普通浮点附件替代位型打包，同时保留 16 位量化；明确越界零值、零法线与分母保护。原鼠标搅动和未启用计算不接入。本例不宣称数值轨迹或全局质量完全一致。

共享播放器仅增加两个可选方法：`prepareFrame(renderer)` 在主画布之前运行离屏过程；`reset()` 让重置按钮同时重建反馈状态。旧案例继续走原有绘制路径，既有断言和容差保持原样。

## 反馈状态与重置

- 初始重演 600 个模拟步；每步依次写 A、B，显示前计算 C。每个模拟步仍使用原作 dt=1.5，播放时间按 60 步/秒推进。
- 最长边 400 的网格与显示 DPR 分开；非默认重力、压力、分布宽度或网格宽高比变化会重演；高光只改变显示，模拟速度只改变之后的推进次数。持久状态 B 和显示密度 C 的三个附件保存默认检查点，恢复时复制全部三个附件并重设模拟时钟；A 是下一步覆盖的临时结果。
- `numeric-validation.json` 保存默认 400×250、600 步后，WebGPU 与 WebGL2 的五个浮点附件逐通道范围和非有限数计数：全部为有限值。
- 开发时新增外观回归测试曾捕捉到缺失液流。生成 shader 与前四步附件读回显示：嵌套 Loop 使用同名默认索引，重复采样了对角线。改用二维 Loop 生成独立的 i/j 索引后，完整 5×5/3×3 邻域恢复，质量不再指数增长。首次失败报告、截图、trace 与生成代码保存在本地忽略目录 `output/playwright/paint-diagnosis-first-failure`。
- 截图夹具隐藏舞台覆盖层后，重置按钮不能再用可见角色定位；夹具改为向实际按钮派发点击。该超时证据保存在 `output/playwright/paint-harness-first-failure`，没有改产品可见性或放宽断言。
- 临时浮点附件诊断入口已从产品源码移除。
- WebGL2 播放后重新求解 600 步时，出现局部轨迹差异（首轮桌面最大字节差 11、移动 201），首次失败报告、截图和 trace 保存在 `output/playwright/paint-reset-first-failure`。两次求解的网格、步数、参数和来源时间相同；底层差异的精确成因未确认。改为默认 GPU 检查点后，四组参数恢复和默认重置均为字节差零，保留原有严格断言，并额外检查从还原状态继续推进的可重复性。非默认参数的重演不承诺跨后端或逐位轨迹一致。

## 本机浏览器与媒体

实际媒体捕获确认 Chromium 151.0.7922.34、WebGPU、NVIDIA/lovelace、fallback=false，强制 WebGL2 对照也已运行。正式 WebP 与 WebM 来自实际 TSL 画布，海报及压缩循环中间帧已目视检查：蓝橙液流、碰撞、薄片和飞溅可辨认，没有只显示底色、黑屏或整体过曝。

硬件当前核验为 AMD Ryzen 9 7950X3D 与 NVIDIA GeForce RTX 4080 SUPER，另有 AMD Radeon 集成显示设备。四组各预热三秒后采样 120 个 RAF 间隔，平均 6.06 ms，P95 6.1–6.2 ms；没有水平溢出或外部请求。移动自动 DPR 1.5；受控 45 ms ×130 帧负载使桌面 DPR 从 1 降到 0.8。

媒体为 960×600；WebP 质量 92。原始浏览器录像用模拟速度 0.6；成品 VP9 WebM 为 25 fps、188 帧、7.52 秒、无音轨，前 94 帧加逆序闭环。倒放仅用于预览媒体，不改变实时模拟。

海报 24974 字节、循环 338884 字节，完整 SHA256 见 `browser-evidence.json`。1001×601 奇数尺寸与默认/全部参数最小值/全部参数最大值在两个后端共六组输出有效、透明度为 255，错误与警告均为零。

本机性能、桌面/移动视口、两个后端、DPR、减少动态效果及受控隐藏事件结果见 `performance.json` 与 `browser-evidence.json`。RAF 间隔是浏览器调度数据，不是 GPU 时间；移动模拟不是实机手机。原生后台标签页没有新的可验证能力，本轮不重复已知仍报告 `document.hidden=false` 的尝试，也不把受控事件当作原生后台证据。

## 原始 GLSL 对照

`reference-comparison.json` 记录原始五段 GLSL 与 TSL WebGL2、以及 TSL 两个后端的 PNG 比较。对照使用相同 400×250 模拟网格、600 步和来源时间 599/60 秒；Image 的包装器只将 960×600 显示坐标映射回网格坐标，五段原始源码不变。三像素外边缘从字节差统计中排除，避免 CSS 边界影响。

反馈模拟会累计浮点与量化差异，局部液滴的位置可以分离；整体流束、混色和碰撞结构需同时目视检查，不能仅凭均值宣称逐像素一致。

内部区域统计：原始 GLSL→TSL WebGPU 最大 156、平均 RGB 字节差 0.180184、超过 10 的分量比例 0.001958；原始 GLSL→TSL WebGL2 最大 140、平均 0.199608、超过 10 的比例 0.002415；TSL WebGPU→WebGL2 最大 158、平均 0.208911、超过 10 的比例 0.002566。两种表示与原作的整体视觉已检查，保留局部差异，不作像素一致或单一原因判断。
