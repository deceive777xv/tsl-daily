## 本机性能基线

Windows，CIM 核验 AMD Ryzen 9 7950X3D / NVIDIA GeForce RTX 4080 SUPER。一次只测试一个页面，每组默认自动画质暖机 3 秒，再采集 120 个 RAF 间隔。这是**浏览器调度观察，不是 GPU 时间戳或真实手机性能**。

| 视口             | 实际后端 | 绘制尺寸 | 有效 DPR | 平均 / P95    |
| ---------------- | -------- | -------- | -------- | ------------- |
| 桌面 1440×900    | WebGPU   | 1440×900 | 1        | 6.06 / 6.2 ms |
| 桌面 1440×900    | WebGL2   | 1440×900 | 1        | 6.06 / 6.1 ms |
| 移动模拟 412×915 | WebGPU   | 618×1372 | 1.5      | 6.06 / 6.2 ms |
| 移动模拟 412×915 | WebGL2   | 618×1372 | 1.5      | 6.06 / 6.1 ms |

四组横向溢出为 0，无外部请求或错误。受控增加每帧 45 ms 主线程负载、持续 130 帧后，自动 DPR 从 **1 降到 0.8**。这是调整策略响应验证，不是 shader 自然负载测量；真实手机未测试。默认七轮共十四个正弦，高层数/频率会带来更细的折痕与潜在走样。

## 减少动态与隐藏暂停

- `prefers-reduced-motion: reduce` 下初始 backend 为空，静态海报成功加载；主动播放后启动真实 WebGPU，按钮变为“暂停动画”。
- 受控 `document.hidden=true` 加 visibilitychange 后，GPU submits 在 800 ms 内保持 **476 → 476**；恢复后为 **614**，按钮随播放状态同步。暂停与恢复路径通过。
- **原生后台标签页行为未验证通过**：真实切换到另一标签页仍报告 `document.hidden=false`，native 采样 submits 为 374 → 374，回到页面后为 474。即使提交数暂时稳定，也不能在 Page Visibility 未报告隐藏时宣称原生隐藏路径通过。此证据与受控事件分开记录。
