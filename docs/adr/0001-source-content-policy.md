# 热门、许可清晰的授权移植优先

每个 Shadertoy 原作都必须先确定有效许可证：优先读取源码顶部的显式许可，若没有声明则采用平台默认的 CC BY-NC-SA 3.0。网站以授权移植为主要内容类型，在有效许可证或作者明确授权的范围内阅读源码并重写为视觉等价的 TSL；灵感重构仅用于有意形成新构图、配色或动态表达的再创作。

候选优先来自 Shadertoy 热门榜、Featured、Shader of the Week，或有显著点赞与浏览量的作品；每个案例保存选材时的热度证据。热度只负责排序，许可证据具有一票否决权。

显式许可证禁止改编、互相冲突或无法可靠判断时，原作直接排除，不读取或迁移源码，也不自动转为近似灵感重构。当前原作中的限制性声明优先于旧镜像中曾出现的 MIT 或 CC 许可；证据有版本冲突时直接跳过。只有保存的当前源码快照顶部未见自定义许可声明时，才能写成“按 Shadertoy 默认许可”。

每个移植都必须记录作者、原作标题与链接、许可证、判断证据、热度证据、修改内容，并履行署名、非商业、相同方式共享或该许可证要求的其他义务。创作者另行授予 Shadertoy 的平台运营许可只服务于 Shadertoy 的运营、推广和改进，不为本网站提供再利用权；实际许可证证据必须随案例保存并进入 PR 审批。
